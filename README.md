# 🃏 كرت فكة

لعبتين في واحدة لمجموعة أصحاب عايزين يلعبوا سوا من موبايلاتهم على **نفس الشبكة** (واي فاي البيت أو هوت سبوت من موبايل حد فيكم).

## 🎮 المودين (صاحب الأوضة بيختار من الشاشة الأولى)

| المود | الفكرة |
|---|---|
| 🎭 **تخمين شخصيات** | كل واحد ياخد شخصية سرية من **نفس الكاتيجوري** (اللي صاحب الأوضة بيختارها)، ونتناوب الأسئلة لحد ما نكشف بعض |
| 🕵️ **لعبة الجاسوس** | الكل بيشوف نفس **الكلمة السرية**، وواحد (أو اتنين حسب ما صاحب الأوضة يحدد) بيشوف «جاسوس» بدلها — اسألوا واكشفوا الجاسوس قبل ما الجواسيس يخلصوا المدنيين |

## 📸 صور الشخصيات ومعلوماتها

في مود التخمين، بطاقة «شخصيتك السرية» بتعرض **صورة حقيقية** للاعبين (محفوظة داخل التطبيق نفسه — تشتغل offline):

- **لاعبو كرة القدم:** صورة حديثة + بطاقة معلومات كاملة (الفريق الحالي، الجنسية، المركز، التقييم، الرقم، القيمة، البطولات 🏆، الإنجازات 🏅، ورحلة الانتقالات 🔄).
- **المشاهير والفنانين والحيوانات والكرتون:** صورة حقيقية (عند وجودها) + وصف مختصر.
- **الوظائف والأكلات والأشياء:** أفاتار إيموجي (مفيش صور حقيقية لسلوكات ومفاهيم).

## 🎚️ مستويات صعوبة لعيبة الكورة (التخمين)

في مود التخمين مع كاتيجوري **الكورة والرياضة**، صاحب الأوضة بيختار مستوى الصعوبة من اللوبي، وكل اللعيبة بتاخد من نفس المستوى:
- 🟢 **سهل:** النجوم والأساطير الأشهر (أعلى تقييم) — ميسي، صلاح، رونالدو...
- 🟡 **متوسط:** نجوم كبار معروفين أوي.
- 🔴 **صعب:** لاعبين أقل شهرة (تقييم أقل) — للي عارفين الكورة كويس 😄.
- 🎲 **الكل:** كل اللعيبة مخلوطين بدون فلترة (الوضع الافتراضي).

## 📚 الكاتيجوريات

صاحب الأوضة بيختار الكاتيجوري من اللوبي (عشوائي مخلوط، الكورة والرياضة، فنانين ومطربين، مشاهير عالم، كرتون وأنمي، حيوانات، وظائف ومهن، أكلات، أو أشياء) — **أزرار مباشرة** (مش قائمة منسدلة)، عشان على الموبايل مفيش نافذة اختيار بتختفي وبتظهر. في **مود التخمين** الكل ياخد شخصيات من نفس الكاتيجوري — على بعضهم.

## 🕵️ قواعد لعبة الجاسوس

1. صاحب الأوضة بيحدد الكاتيجوري (أكلات مثلًا) وعدد الجواسيس (1 أو 2).
2. الكل (ما عدا الجواسيس) شايف **نفس الكلمة** — الجاسوس شايف بس «جاسوس» 🕵️.
3. الدور بيتناوب بالأسئلة (نعم/لا) — الجاسوس بيحاول يندمج ويفهم إحنا ماشيين على إيه.
4. أي لاعب يقدر يضغط **«اتهم بالجاسوسية»** ويشاور على واحد.
   - ✅ لو كان جاسوس فعلًا → **المدنيين يكسبوا** والكلمة تنكشف.
   - ❌ لو كان مدني → **المشتكي بيخرج** من اللعب بدال الجاسوس.
5. **الجواسيس يكسبوا** لو المدنيين كلهم خرجوا (اتهموا غلط) أو لو فاضل عدد مدنيين = عدد جواسيس.
6. لو الجاسوس نفسه ساب الأوضة — المدنيين يكسبوا 😅.

> محتاجة **3 لاعبين على الأقل**.

## 🎭 قواعد التخمين (الكلاسيكية)

1. كل لاعب بيفتح اللعبة على موبايله ويكتب اسمه.
2. واحد فيكم يعمل أوضة جديدة → بياخد **كود** (5 حروف/أرقام) وبيبعته لصحابه + الرابط/الـ IP.
3. الباقيين يكتبوا الكود وينضموا.
4. صاحب الأوضة بيختار **الكاتيجوري** ويضغط ابدأ → كل لاعب ياخد شخصية سرية من نفس الكاتيجوري.
5. الدور بيتناوب بالأسئلة (نعم/لا) شفهيًا أو في الشاات.
6. لما حد يحس إنه عرف شخصية خصمه → **🔍 خمّن شخصية**.
   - ✅ لو صح: اللي اتخمّنت شخصيته بيخرج من الجولة.
   - ❌ لو غلط: اللي خمّن هو اللي بيخرج.
7. آخر واحد فاضل **الفايز** 🏆 → جولة تانية فورًا بشخصيات/كلمات جديدة.

> مع 2 لاعبين: أول واحد يعرف شخصية التاني يكسب. مع 3 أو أكتر: بيطردوا واحد ورا التاني.

## المتطلبات

- **Node.js** (الإصدار 18 أو أحدث) على اللابتوب أو أي جهاز هتستضيف عليه.
- موبايلات أصحابك متصلة **بنفس الواي فاي أو الهوت سبوت**.

## التشغيل

```bash
# أول مرة بس:
npm install

# بعدين كده:
npm start
```

هتشوف في الطرفية:

```
   افتح على جهازك:       http://localhost:3000
   اللعيبة يفتحوا:       http://192.168.1.4:3000
```

- **إنت** افتح `http://localhost:3000` واعمل أوضة.
- **صحابك** يفتحوا من موبايلاتهم `http://192.168.1.4:3000` ويكتبوا كود الأوضة.

## لو صحابك مش قادرين يفتحوا الرابط

- **الوضع الأكيد:** حد فيكم يعمل **هوت سبوت** من موبايله، واللابتوب + موبايلات الباقيين يتصلوا بيه.
- **الجدار الناري (Windows):** أول تشغيل هيطلعلك سؤال من Windows Firewall — اختار **السماح (Allow)** للشبكات الخاصة.
- **التأكد من الـ IP:** من اللابتوب اعمل `ipconfig` في CMD وشوف IPv4 بتاع المحول اللي متصل بيه الشبكة.

## 🌍 اللعب أونلاين (من أي مكان في العالم)

نفس اللعبة بالظبط، لكن السيرفر متاح على الإنترنت — الصحاب يلعبوا حتى لو مش على نفس الشبكة.

### الخيار الموصى به (مجاني 100% من غير لابتوب — Replit)
استضافة اللعبة على **Replit** — الرابط موجود دايمًا ويفيق في ثواني أول ما حد يفتحه، ومن غير أي جهاز عندك:
1. اعمل حساب مجاني على [replit.com](https://replit.com) (تسجيل بالإيميل — بدون كارت).
2. **+ Create** → **Import from GitHub** → الصق: `https://github.com/hassan00980/kart-faka-web`.
3. ملف `.replit` موجود جاهزًا في الريبو — اضغط **Run** وبتشتغل مباشرة.
4. **Publish** (سيّب Autoscale — الإعداد المجاني) ← خد رابطك `https://اسم-المشروع.replit.app` ← ابعته للصحاب أي مكان 🌍.
- تنبيه: التطبيق المجاني بيحيا **30 يوم** وبعدها يتجدد بضغطة **Republish** واحدة.

### الخيار 1 (المجاني الفوري — من غير كارت ولا حساب): نفق Cloudflare
بنعرض سيرفر اللعبة على الإنترنت برابط مباشر (WebSocket مدعوم بالكامل):
```powershell
powershell -File start-online.ps1     # → يطلعلك رابط https://xxx.trycloudflare.com
```
- السكربت بيشغّل `server.js` + نفق Cloudflare وبيطبعلك **رابط المشاركة** — ابعته للصحاب أي مكان 🌍.
- شرط وحيد: الجهاز اللي شغال عليه يفضل مفتوح طول الجلسة (نفس فكرة الأوفلاين، بس عالميًا).
- تقدر كمان تعمل النفق يدويًا: نزّل `cloudflared` وشغّل:
  ```
  cloudflared tunnel --url http://localhost:3000
  ```

### الخيار 2: استضافة دايمة على Render (الخطة المجانية اتشالت — محتاجة دفع)
1. ارفع المشروع على GitHub (الريبو موجود: `hassan00980/kart-faka`).
2. في [Render](https://render.com) اعمل **New → Web Service** والصق رابط الريبو العام.
3. Render هيستدل تلقائيًا على `Dockerfile` — بعدها بيطلب خطة **Starter (~$7/شهر)** دي اللي بقت إلزامية للـ web services.
4. الميزة: استضافة 24/7 من غير ما تفتح جهازك. بديل آلي لو معاك مفتاح API:
   `powershell -File render-deploy.ps1 -ApiKey "rnd_..."`

### الخيار 3: سيرفر خاص بك (VPS)
```bash
git clone https://github.com/hassan00980/kart-faka.git && cd kart-faka
npm install --omit=dev
PORT=3000 node server.js   # قدام nginx/PM2 لو محتاج
```

### بعد النشر
- **صاحب الأوضة** يفتح رابط السيرفر → في اللوبي يظهرله **لينك المشاركة** (بزر «📋 انسخ اللينك» + رمز QR) — يبعته للصحاب أي مكان في العالم 🌍.
- الصحاب يفتحوا اللينك أو يكتبوا **كود الأوضة** ويلعبوا عادي.
- **الكود بقى 5 حروف/أرقام** للأمان أونلاين، ووضع الأوفلاين (نفس الشبكة/الهوت سبوت) شغال زي ما هو — اللوبي بيظهر سطر «على نفس الشبكة» كبديل.
- **من التطبيق (الـ APK):** في شاشة «👥 انضم كلاعب» استخدم خانة «اكتب العنوان يدويًا» والصق رابط الأونلاين (يبدأ بـ `https://`) — التطبيق يوصلك بالأوضة الأونلاين مباشرة. العنوان المحلي (مثل `192.168.43.1`) يشتغل زي ما هو.
- الأوضة بتفضل مفتوحة طول ما صفحة صاحب الأوضة مفتوحة — زي الأوفلاين بالظبط.

## أوامر مفيدة (بيئة التطوير)

| الفعل | الأمر |
|---|---|
| تثبيت الجيزيات (Express + Socket.IO + أدوات الفحص `jsdom`/`docx`) | `npm install` |
| تشغيل اللعبة | `npm start` |
| فحص السيرفر (95 فحصًا) | `node test.js` |
| فحص الواجهة (141 فحصًا) | `node ui-smoke.js` |
| فحص خادم الأندرويد (~100 فحص) | راجع `android/README.md` (javac + TestServer) |
| بناء www الأندرويد من public | `node build-apk-www.js` |
| بناء الـ APK | `gradle :app:assembleDebug` من `android/khammeni-android` |
| توليد توثيق الوورد | `node tools/make-word-doc.js` ثم فحصه بـ `node tools/verify-docx.js` |
| تغيير البورت (لو 3000 مشغول) | `$env:PORT=4000; npm start` |

### قاعدة ذهبية قبل أي إضافة جديدة
1. نفّذ الفحوصات الثلاثة (95 + 141 + ~100) — لازم كلها خضرا.
2. الإضافة لازم تتوفر على **المنصتين**: ويب (`server.js` + `public/client.js`) وأندرويد (`GameServer.java` + شيم `build-apk-www.js`).
3. حوادث الـ Socket (مثل `set-difficulty`) لازم تكون مسجّلة في `EVENTS` داخل `build-apk-www.js` عشان تعمل على الأندرويد.
4. أي معالج سوكيت لازم يعمل `ack` حتى عند الرفض (`ok:false`) — وإلا يتعلق emit في الاختبارات.
5. نقطة المرجع الأخيرة = tag `ref-v5-final`. أي شغل جديد يبني عليها أو يفرّع منها.
